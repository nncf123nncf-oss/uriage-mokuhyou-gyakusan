# Day 038｜売上目標逆算ツール

> 100日100プロダクトチャレンジ Day 038（2026-09-14）／カテゴリ: 売上・計算ツール

## これは何か

月の売上目標額と客単価を入力すると、目標達成に必要な客数と1日あたりの客数を逆算します。
客単価を上げた場合の比較も併せて表示します。

## 解決する困りごと

- 想定利用者: 月商目標を立てたい店舗・サロン・教室の事業者
- 困りごと: 売上目標はあるが、必要な客数が分からない
- 解決方法: 目標額・客単価・営業日数を入れるだけで、必要客数と1日あたりの客数を自動計算し、客単価を上げた場合との比較も出す

## 使い方

`index.html` をブラウザで開き、月の売上目標額・客単価・今月の営業日数を入力します。
入力するたびに自動で再計算されます。比較したい客単価を入れると、その場合の必要客数も表示されます。
ビルド・インストール・ネット接続はいりません。

## 主な機能

- 機能1: 目標額 ÷ 客単価 → 必要客数（切り上げ）
- 機能2: 営業日数で割った1日あたりの客数（小数第1位まで）
- 機能3: 比較したい客単価を入れた場合の必要客数・1日あたり客数・差分の表示
